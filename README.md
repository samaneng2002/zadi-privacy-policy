# Zadi Privacy Policy

Static, crawler-friendly hosting for the [Zadi](https://github.com/samaneng2002/nurani) app's privacy policy — plain HTML via GitHub Pages, chosen specifically because Google Play's automated URL checker had trouble reliably accessing a Google Docs share link (JS-rendered, occasional redirects) even though it opened fine in a real browser.

Live pages:

- **Google Play (AdMob) version**: https://samaneng2002.github.io/zadi-privacy-policy/google.html
- **Huawei AppGallery (Petal Ads) version**: https://samaneng2002.github.io/zadi-privacy-policy/huawei.html

To update: edit `google.html` or `huawei.html` directly and push to `main` — GitHub Pages redeploys automatically within a minute or two.
